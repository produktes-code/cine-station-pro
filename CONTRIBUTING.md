# Contributing to CineStation Pro

Thank you for choosing to contribute to CineStation Pro! We welcome community contributions to help improve this virtual cinematography workspace.

## Code of Conduct
Please make sure to be respectful and constructive in all community discussions and contributions.

## How to Contribute

### Reporting Bugs
1. Search the open issues to see if the bug has already been reported.
2. If it is new, open a new Issue, detailing:
   - Your environment (OS, node/python version)
   - Steps to reproduce the bug
   - Stderr/console outputs and logs

### Suggesting Enhancements
1. Open an Issue with the prefix `[Feature Request]`.
2. Clearly explain:
   - What feature or automation you propose.
   - The workflow and user benefits.

### Pull Requests
1. Fork the repository and create your branch from `main`.
2. Verify that your code complies with the project style guidelines:
   - **Backend (Python):** Stays PEP8 compliant. Run `flake8` checks.
   - **Frontend (Node):** Run `npm run build` locally to verify compilation.
3. Commit your changes with semantic, descriptive messages.
4. Open a Pull Request pointing to the `main` branch.
